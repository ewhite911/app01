## 1. 한 페이지 경영진 요약

**결론: 지금 개발할 것은 "3단계 기도·묵상 루틴 앱"(가칭 Selah 계열) 하나다. 기도+앱 차단은 권한 승인 후, AI 성경 챗봇과 수면 오디오 앱은 개발하지 않는다.**

| 구분 | 결론 |
|---|---|
| ① 지금 개발할 것 | **매일 3단계(말씀 1구절 → 기도제목 기록·기도 타이머 → 마무리 후 YouTube 가스펠 재생목록) 루틴 앱**. 로그인 없음, 기도기록 기기 내부 저장, AI 없음, 월 $3.99·연 $24.99·평생 $59.99, 체험 종료일 알림, 1탭 해지. 2주 프로토타입 → 6주 베타 → 12주 출시 |
| ② 검증 후 개발할 것 | **기도해야 SNS 잠금 해제(PrayScreen형)**: iOS Family Controls(Distribution) entitlement 승인 확인 후 v1.1. **AI 개인화 기도문 초안**: 유료·옵트인·"하나님의 메시지가 아님" 고지·핫라인 탑재 조건으로 v1.2 이후 검토. **한국어판**: 국내 번역본 저작권 확인 후 |
| ③ 개발하지 않을 것 | AI 성경 질문·신앙상담 챗봇(경쟁 포화·환각 15~60%·교리 편향 연구·주법 규제), 수면 성경 오디오(성우·오디오 엔진 비용, Dwell·Abide가 리뷰에서 오디오 오류로 고전), 교회·소그룹 앱(B2B 영업 채널 필요), 어린이 신앙교육(무료 대형 IP 독점·COPPA) |

**영상 전략 검증 결과**: 원본 인물은 Lotanna "Lotts" Ezeike(전 Barclays, 현 YC W26 Grade CEO). 앱 4개(Bible Buddy·Magic Music·Toxic Traits·Pray Screen) 중 3개의 존재와 소유권 이전 정황은 스토어에서 확인됐다. 그러나 **총 매각액 $500k, D30 리텐션 60%, CPI $0.30~0.50, 이메일 120만 명은 전부 본인 진술**이며 독립 확인 불가. 매각배수 "2~4배"는 **연간 이익(EBITDA) 기준**으로 원본 자막에서 확인됐고 Acquire.com(소형 3.7x)·Flippa(앱 2.93~3.39x) 관행과 부합한다. 한국어판 제목("1년만에 7억", "바이브코딩", "비개발자")은 원본에 없는 재포장이며, 채널은 유료 구독($29~39/월) 홍보 링크를 달고 있다. RevenueCat 2026 기준 신규 앱이 2년 내 $10k MRR에 도달할 확률은 4.6%이므로 영상의 결과는 일반화할 수 없다.

**시장**: 매출은 Hallow(2025 순매출 약 $40M 추정)·Bible Chat(월 $750K~900K 추정)에, 다운로드는 무료 YouVersion(10억 설치)에 집중된 양극 구조. 상위 앱의 성장 엔진(유명인·슈퍼볼·교구 파트너십·Apple Search Ads 2,000개 키워드)은 전부 자본 의존적이다. 개인 개발자가 실제로 진입한 영역은 "기도+앱 차단", "스트릭·습관", 소규모 AI 챗이며, 리뷰 수 수십~수천 건, 주 단위 구독이 흔하다.

**저평점 리뷰(10개 앱 968건 실표본)**: 1위 앱 충돌·동기화(24%), 2위 신앙의 상업화 반감(22%), 3위 무료 기능 축소(16%). 결제 계열(무료체험·해지·가격·유료화·상업화) 합산이 저평점의 절반 이상. 신학·AI 계열은 8%. 리뷰가 직접 지불 의향을 말한다: "월 2~5달러", "주 6.99 대신 월 6.99면 100% 낸다".

**시장의 빈틈 5개**: ① 정직한 저가 월 요금 + 카드 없는 무료 핵심 + 1탭 해지 ② 로그인 없는 기기 내부 기도기록 ③ 3문항 이하 온보딩·3단계 루틴 ④ "무료 범위 축소 금지" 공개 서약 ⑤ 업데이트 회귀 없는 경량 앱.

**보수적 손익(기준 시나리오, 추정)**: MAU 1만 명·유료 3%·순 ARPPU 월 $2.30 → 월 순매출 약 $690, 고정비 약 $280 → 월 이익 약 $410. MAU 10만 명 → 월 순매출 약 $6,900, 이익 약 $6,200. 손익분기점은 유료 사용자 약 87명(월 $200 고정비 기준). **저가 정책 때문에 유료 광고(CPI $2~5)로는 CAC가 LTV를 넘는다** → 획득은 오가닉(ASO·YouTube·Shorts·UGC 셀프셀렉션)이 전제이며, 이것이 가장 실패 확률 높은 가정이다.

**개발 환경**: React Native + Expo(EAS) 확정. Windows ARM64에서 Node·Expo CLI·adb·실기기 디버깅 가능, Android Studio 에뮬레이터는 미지원 → 실기기 + EAS 클라우드 빌드. Mac 없이 TestFlight까지 가능(EAS 무료 플랜 월 iOS 15회). 성경은 BSB·WEB(퍼블릭 도메인)만 전체 수록.

**중단 기준**: 랜딩 사전등록률 2% 미만, 설치 후 첫 기도 완료율 30% 미만, D7 유지율 8% 미만, 체험→유료 20% 미만, 환불률 6% 초과 중 두 개 이상 해당 시 중단.

### 2-5. 생존자 편향 평가

- Starter Story는 성공 사례만 인터뷰하고 수치를 검증하지 않는다. 인터뷰이는 UGC 지급 툴(CreatorCheck)과 현재 회사(Grade)의 창업자로 노출이 사업에 유리하다.
- 기저율: RevenueCat SOSA 2026(115,000개+ 앱) 기준 신규 앱 2년 내 $1,000 MRR 도달 17.3%, **$10,000 MRR 도달 4.6%**. 2020년 이전 출시 앱이 구독 매출의 69%. AI 앱은 12개월 리텐션이 일반 앱보다 36% 나쁨. (https://www.revenuecat.com/state-of-subscription-apps, 2026-09-17)
- 매각된 앱의 현재: Magic Music 2024년 이후, Bible Buddy 2024-12 이후, Pray Screen 2025-09 이후 업데이트 없음. Pray Screen iOS 저평점 68건 중 상업화 반감 49%, 차단 오작동 29%. **판 사람은 현금화했지만 앱의 장기 생존은 확인되지 않는다.**
- 동일 카테고리 실패 사례(제3자): Bible AI "93만 뷰까지 올린 뒤 사라짐", Prayer Project "1억 뷰에도 전환 부진". (https://www.socialgrowthengineers.com/forgive-me-father-for-i-have-created-another-bible-app-2, 2026-09-17)

## 10. 최종 추천에 대한 반대 논거

1. **무료 대체재가 너무 좋다.** Lectio 365는 매일 새 묵상을 무료로, YouVersion은 스트릭·기도·오늘의 말씀을 무료로 준다. 우리 앱의 유료 전환은 "기록·회고 편의"에만 기대는데, 이것이 월 $3.99의 가치인지 검증되지 않았다.
2. **기술 장벽이 없다.** 12주면 누구나 만든다. Pray Screen 니치에 출시 후 수십 개가 따라온 것처럼, 성공하면 즉시 복제된다.
3. **저가 정책이 성장을 봉쇄한다.** CPI $2~5(Meta)·설치→유료 3%면 유료 사용자 1명 획득에 $67~167이 드는데 LTV는 약 $21(추정)이다. 유료 광고를 못 쓰면 오가닉만 남고, 오가닉은 통제 불가능하다.
4. **"정직함"은 광고에 안 나온다.** 10초 숏폼에서 "자동결제 함정 없음"은 훅이 되기 어렵다. 경쟁 앱의 감정적 크리에이티브(유명인 목소리, 눈물 간증)에 밀린다.
5. **콘텐츠 신선도 부재.** 오늘의 말씀 365일은 1년 뒤 반복된다. 매일 새 묵상을 쓸 집필팀이 없다.
6. **영상의 플레이북과 어긋난다.** 영상은 UGC 대량 생산 → 메타 광고 → 매각인데, 우리는 광고를 못 쓴다. 매각 배수는 성장 곡선에 붙는데 오가닉 성장은 곡선이 완만하다.
7. **한국인 개발자의 미국 영어권 종교 시장.** 문화적 뉘앙스(교단·정치·표현)를 놓칠 위험. 목회자 검수 1명이 필수.
8. **계절성 의존.** 사순절·신년 외 기간의 유입이 얇다.

반대 논거에 대한 답: 1·5는 "기록 앱"으로 포지션을 명확히 하고 검증 단계에서 유료 전환율로 판단한다. 3·4·6은 리포트가 인정하는 핵심 리스크이며, 15장 검증계획과 16장 중단 기준으로 통제한다. 2는 방어 불가 → 빠른 매각 옵션을 열어 두는 것으로 대응한다.

### 13-3. iOS 클라우드 빌드·TestFlight / Android 실기기 / Mac 필요 시점

- iOS: Apple Developer $99/년 → `eas build -p ios` → EAS가 인증서·프로비저닝 자동 생성 → `eas submit` → TestFlight. EAS 무료 플랜 월 iOS 15회·Android 15회(저우선순위). 부족하면 Starter $19/월.
- Android: EAS Build APK(내부 배포) → adb/QR 설치. Expo Go는 RevenueCat 모듈 때문에 불가 → Development Build. Google Play 개인 계정 $25, **12명 테스터 × 14일 연속 비공개 테스트** 후 프로덕션 신청.
- Mac 없이 가능한 범위: 빌드·서명·TestFlight·스토어 제출·OTA·크래시 로그 전부. 스크린샷은 실기기 캡처+목업.
- Mac/클라우드 Mac($99~164/월)이 필요한 시점: Xcode로만 잡히는 네이티브 크래시, entitlement 서명 오류(앱 차단 기능 도입 시), 시뮬레이터 특정 OS 조합 재현.

### 13-4. 기기 내부 저장 구조

expo-sqlite(기도제목·루틴 기록) + react-native-mmkv(설정) + expo-secure-store(백업 암호키). iOS 파일 보호 기본값 유지, Android `allowBackup` + dataExtractionRules로 클라우드 백업 제외 옵션 제공. 사용자 주도 JSON 내보내기. 구독 복원은 RevenueCat 익명 ID + 스토어 영수증(계정 불필요).

### 13-5. 구독 결제·YouTube 전환

- RevenueCat: MTR $2,500까지 무료, 초과 1%. react-native-iap는 2026-04 아카이브 → 사용 금지.
- Apple 3.1.2: 구독명·기간·가격·체험 종료 후 청구액 명시, 가격이 가장 눈에 띄게, 복원 버튼, EULA·개인정보 링크. Google Play 계정 보류 기본값 변경(2025-12) 확인.
- YouTube: `Linking.openURL("https://www.youtube.com/playlist?list=PL…")` 하나. iOS Universal Link·Android App Link로 앱 실행, 미설치 시 웹. API 미사용이므로 YouTube API 약관 비대상. Apple 4.2 대비 심사 노트에 "루틴·기록이 본체, YouTube는 마지막 선택 단계"를 명시.

## 16. 중단 기준

다음 중 **두 개 이상**이 4주 검증 종료 시점에 해당하면 개발을 중단하고 리포트를 재작성한다.

1. 랜딩 사전등록률 2% 미만(방문 500명 이상 기준)
2. 인터뷰 10명 중 "월 $3.99를 내겠다" 4명 미만
3. 베타 첫 기도 완료율 30% 미만
4. 베타 D7 유지율 7% 미만
5. 체험→유료 전환 20% 미만(표본 50명 이상)
6. 환불률 6% 초과
7. Apple 4.2 거절 2회(위젯·회고 보강 후에도)
8. 기도 완료 후 YouTube 이동률 10% 미만이면 채널 연동만 중단(앱은 계속)

하나만 해당하면 "수정" 열의 조치(온보딩·가격·결제 시점 변경) 후 2주 재측정.
