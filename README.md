# Selah Daily — 기도 루틴 앱 프로젝트

하루 5분 기도 루틴 앱(가칭 Selah Daily)의 시장조사와 MVP 코드를 담은 저장소입니다.

| 폴더 | 내용 |
|---|---|
| `selah-daily/` | Expo SDK 57 앱 코드. 실행·빌드·출시 방법은 `selah-daily/README.md` |
| `selah-daily/docs/` | 추가 아이디어, 이미지 가이드·프롬프트, **대화 결정사항(아직 코드에 반영 안 된 합의 포함)** |
| `종교앱-시장조사/` | 심층 분석 리포트(19장), 조사 원자료 01~08, 스토어 목업·워크플로우 HTML, 디자인 소스 이미지 |

## 다른 PC에서 이어서 작업하기

```bash
git clone <이 저장소 URL>
cd <저장소>/selah-daily
npm install
npx expo start
```

- Node.js 20 이상 필요. Android Studio·Mac은 필요 없습니다(빌드는 EAS 클라우드).
- 이어서 할 일은 `selah-daily/docs/결정사항_및_다음작업.md`부터 읽으세요.
- 이 저장소는 `D:\디자인\etsy`의 다른 폴더(MAS, dino-game 등)는 추적하지 않습니다.
