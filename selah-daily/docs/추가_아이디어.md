## 0. 전제 — MVP 확정 범위(변경 금지)

| 화면 | 내용 |
|---|---|
| ① 오늘 | BSB 말씀 1구절 → 기도제목 체크 + 3분 타이머 → 아멘 → YouTube 재생목록 버튼 |
| ② 기도제목 | 목록·추가·"응답됨" 표시 |
| ③ 결제 | 월 $3.99 단일, 7일 체험, 종료일 표시, 종료 2일 전 알림 + 캘린더 일정 추가 |
| ④ 설정 | 알림 시각 1개, 구독 해지 링크, JSON 내보내기, 개인정보·초교파 고지 |
| 제외 | 서버·계정·AI·앱 내 오디오·광고·스트릭·요일 스트립·회고·위젯·테마 |

출시 순서: Google Play 먼저, iOS는 나중. 아래 "언제" 열의 v1.1 = Play 출시 후 첫 기능 업데이트, v1.2 = iOS 출시와 함께 또는 그 직후.

판단 원칙 3가지
1. 리뷰 1위 문제가 "충돌·동기화"(235건, 24.3%)이므로 **회귀 표면적을 넓히는 기능일수록 뒤로** 미룬다.
2. 무료 축소(152건, 15.7%)·상업화 반감(217건, 22.4%)을 피하려면 **한 번 무료로 준 것은 유료로 돌리지 않는다.** 새 기능만 유료 후보.
3. 교리·정치 편향은 빈도 8%지만 "즉시 삭제 유형"(리포트 5-3)이므로 콘텐츠형 기능은 반드시 목회자 검수·초교파 원칙을 거친다.
